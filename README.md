## 功能

- 播放 MP4、HLS、DASH/MPD 等媒体，支持进度拖动、音量、倍速、断点续播和全屏；HLS 与 DASH 播放组件随项目提供。
- 手机端在视频画面左右滑动可快进、快退，滑动时显示目标时间，松手跳转；上滑可取消本次跳转。
- 手机端单击画面显示控件，双击暂停或继续播放；滑动快进与双击分别识别。
- 画面左侧的小锁可以锁定播放控件、快捷键与触摸手势；播放状态保持不变，再次点击小锁解锁。小锁闲置 3 秒后隐藏，鼠标移动或点击画面时显示；锁定时点击画面只唤出解锁入口。
- 右键菜单提供视频色彩、音效、快捷键说明和统计信息；音效包含预设、3 / 5 / 10 段均衡器及增益。
- 可在后台配置右键菜单的站点按钮名称和链接，点击后在新标签页打开。
- 播放设置包含镜像、循环、自动开播、播完切集或暂停、画面比例、隐藏黑边、关灯、音量均衡和画中画方式。
- 进度预览读取真实视频帧；高能进度条来自实际弹幕密度，可关闭。
- 支持本站弹幕库和多个外部弹幕库，按视频标识依次匹配，支持空库创建配置和本站数据库兜底。
- 选集支持内置平台列表及配置的资源站；按原链接定位当前项，保留正片与特别节目的名称。
- 默认使用可显示弹幕的 Document Picture-in-Picture；小窗控件保持精简，保留弹幕开关、倍速和竖向音量。
- 后台提供概览、播放器、接口设置、本地弹幕和部署说明，支持明暗主题及手机导航。
- 首页可开启 404 页面开关，默认关闭；开启后仅不带播放链接的首页返回 404。
- 返回标签页或切换播放窗口时检查画面是否恢复，保持用户原来的播放、暂停状态。

清晰度、编码和平台剧集的可用范围取决于实际片源与接口。编码选项只切换片源提供的编码，不会在浏览器中转码。

## 环境要求

| 项目 | 要求 |
| --- | --- |
| PHP | 8.2 或更新版本，建议使用仍受支持的分支 |
| PHP 扩展 | PDO、PDO MySQL、cURL、OpenSSL；JSON 支持；网页解析和 DASH 清单转发还需 DOM / libxml |
| 数据库 | MySQL / MariaDB，支持 InnoDB 与 utf8mb4 |
| Web 服务器 | Apache、Nginx 或配置了 PHP FastCGI 的 IIS |
| 浏览器 | 当前版本的 Chrome、Edge、Firefox、Safari；部分功能受浏览器能力限制 |
| 构建 | Node.js，仅修改前端源码后需要；部署已构建文件不需要 Node.js |


安装时项目根目录及 `includes/` 需要可写。运行时让 PHP 进程可以写入 `Cache/`、`var/`，不要把这些目录作为公开静态资源提供。

## 首次安装

1. 将发行目录上传到站点根目录，保留 `assets/`、`class/`、`includes/`、`install/` 和访问限制文件。
2. 创建一个空数据库及仅供此站点使用的数据库账号。
3. 打开 `https://你的站点/install/`。页面会自动检查 PHP 扩展及目录写入权限；缺少的项目可在服务器面板中处理。
4. 填写数据库连接信息，创建**独立的站点管理员账号**，并输入两次管理员密码（12–72 字节）。点击“完成安装”。无需服务器终端或手动创建安装密钥文件。
5. 安装成功后点击“进入后台登录”，使用刚创建的管理员账号。安装器会写入数据库配置、管理员密码哈希及 `install.lock`。

数据库账号不等于后台管理员。项目没有可通用登录的默认管理员密码，也不使用旧版后台安全码登录。

新站上传后应立即完成安装，再开放给访客。需要预先限制安装访问的部署可选择运行 `php tools/setup-token.php`，或配置 `XPLAYER_INSTALL_TOKEN` 环境变量；只有已配置安装令牌时，页面才要求输入令牌，成功后删除临时令牌文件。已有令牌配置无效时不会跳过验证。

安装器拒绝覆盖已有安装锁、数据库配置、管理员配置或同名数据表；已有站点升级不需要重新安装。

### 修改管理员密码与已有站点

登录后台后，在“播放器”设置页的“修改管理员密码”中输入原密码，再输入两次新密码。保存成功后会返回登录页，使用新密码重新登录；其他旧登录会话同时失效。

升级前备份数据库及 `includes/Mysql.Include.php`、`includes/Admin.Credentials.php`、`install.lock`，更新程序时保留它们。不要通过删除安装锁来升级。

仅在旧站尚无管理员账号，或忘记密码而无法登录时，才需要通过服务器维护工具创建或重置账号：

```sh
php tools/create-admin.php --username=admin --password-stdin
```

执行后从标准输入提供密码并回车。重置已有管理员时追加 `--replace`；重置会使旧登录会话失效。不要把真实密码作为命令参数写入命令历史。

## 接入播放链接

播放器首页可以直接输入媒体地址、平台播放页地址或片名。接入其他网站时，给 `url` 参数传入经过 URL 编码的地址：

```text
https://player.example.com/?url=https%3A%2F%2Fmedia.example.com%2Fmovie.mp4
```

嵌入示例：

```html
<iframe id="player" title="视频播放器"
        allow="autoplay; fullscreen; picture-in-picture" allowfullscreen
        style="width:100%;aspect-ratio:16/9;border:0"></iframe>
<script>
  const source = 'https://media.example.com/movie.mp4';
  document.getElementById('player').src =
    'https://player.example.com/?url=' + encodeURIComponent(source);
</script>
```

请编码**整个**原链接，避免原链接中的 `&`、`+` 或 `#` 被误当成播放器参数。可附加 `title` 作为显示标题、`sid` 作为集号；自动识别到的剧集信息会用于定位当前集。`id` 涉及弹幕库标识，普通接入不必填写，也不要用随意的值绑定不同视频。

- 媒体直链通常不需要解析接口。
- 平台网页地址需要配置可用的解析接口。
- 片名搜索和选集需要可用的资源站；仅有播放直链并不意味着一定能获取整部剧集。

## 后台配置

每组设置都有保存按钮，长表单的保存栏随页面滚动保持可见。保存成功或失败时，页面右上角和保存按钮旁同时显示结果；失败时保留输入，便于修正后重试。保存后刷新播放页；浏览器记住的个人播放设置可能覆盖站点的默认开播行为。

### 播放器与外观

在“播放器”页设置标题、图标、LOGO、背景、主题色、弹幕与剧集开关，以及播放提示。广告为可选项，图片或视频素材、跳转地址分别填写。

“推广与扩展信息”中的“站点按钮名称”和“站点按钮链接”共同控制右键菜单底部的站点入口。两项填写并保存后刷新播放页即可显示；任一项留空则隐藏。链接支持完整 HTTP(S) 地址或本站相对路径，例如 `https://example.com/`、`assets/docs/player.html`，点击后在新标签页打开。名称和链接可包含逗号，无需手工拼接。

“首页显示 404”开启后，无 `url` 或 `url` 为空的首页返回简洁的 404 页面和 HTTP 404 状态；带视频链接的播放页、安装入口及后台继续按各自访问规则工作。

后台明暗主题保存在当前浏览器，不修改站点播放器主题。后台通过管理员登录会话验证身份，保存操作检查 CSRF 令牌。

“静态资源”中的“使用 CDN 在线资源”默认关闭。开启后，前台播放器的 JS、CSS、内置 LOGO、图标和弹幕徽章使用 `https://cdn.jsdelivr.net/gh/XG2020/Xplayer@版本/`，CSS 引用的图片也随之走同一仓库版本。解析、弹幕、在线人数等 PHP 接口仍访问本站；自定义上传图片、外部封面和视频地址保持原样。后台始终使用本站资源，CDN 不可用时仍可登录关闭开关。

“CDN 版本”默认 `main`，支持不含斜杠的分支、标签或提交 SHA。先将构建后的 `assets/` 与对应代码同步到公开 GitHub 仓库，再部署同版本到服务器并开启开关。推荐填写固定标签或提交 SHA，避免分支缓存导致新旧资源混用；本地修改后仅上传服务器，不会自动更新 GitHub 或 jsDelivr。关闭 CDN 开关即可恢复本地资源，修改设置后刷新播放页生效。

“播放页保护”中的“防开发者调试”默认关闭，开启后可选择两种模式：

- **稳妥模式（默认）**：拦截 F12、Ctrl+Shift+I/J/C 或 macOS 的 Command+Option+I/J/C，不通过窗口尺寸猜测，避免侧栏和缩放导致误关。
- **加强模式**：保留快捷键拦截，并根据持续的窗口尺寸差尝试检测停靠的开发者工具。侧栏、部分缩放也可能出现同样尺寸，导致误关；移动端、全屏和 iframe 中不启用尺寸判断。

触发后停止播放并尝试关闭当前页面；浏览器不允许关闭时跳转到空白页。后台及未输入视频的首页不受影响。浏览器没有可靠的开发者工具检测接口，从菜单、独立窗口或预先打开工具等方式可能无法拦截；此选项不能保护已下发的源码或媒体地址。更改设置后刷新播放页生效。

### 视频解析

“接口设置”中的通用解析接口每行一个，按顺序尝试，JSON 与网页解析接口可以混用，无需选择类型。支持地址前缀或 `{url}` 模板：

```text
https://parser.example.com/parse?url=
https://parser.example.com/parse?source={url}
```

特定平台可配置专线，格式为：

```text
video.example.com|https://parser.example.com/parse?url=
```

匹配的域名专线先于通用接口。JSON 接口至少提供合法的 HTTP(S) 媒体地址，例如：

```json
{"code":200,"url":"https://media.example.com/movie.m3u8"}
```

也兼容 `data.url`。可附带 `type`（`hls` / `m3u8`、`dash` / `mpd`、`flv`），用于识别没有文件扩展名的播放地址；类型会随解析结果一起缓存。

网页解析接口填写方法相同，例如 `https://parser.example.com/player/?url=`。服务器读取页面并提取媒体地址，成功后交给本站播放器，继续使用本站的弹幕、选集及播放控件。目前支持：

- 页面中的 `video` / `audio` / `source` 媒体地址，以及有限层数的内嵌播放器页面。
- DPlayer、Artplayer、Clappr、ckplayer、JW Player 等常见初始化配置中的字面量媒体地址，以及 `player_aaaa` 一类配置的 URL 编码和 Base64 地址。
- 页面通过 `playerConfig.videoUrl`、`apiToken` 和 `assets/player.js` 使用同站 `api/resolve.php?token=…` 返回媒体 JSON 的解析流程。
- AlphaPlayer 页面内携带加密播放结果的流程：在匹配页面结构和脚本路径后解码，仅接受原视频地址一致且解析成功的媒体结果；不会执行对方脚本或导入其广告、配置。

网页解析需要 PHP DOM 扩展。每条接口最多读取 3 个页面或解析响应，单次响应最多 2 MiB、累计最多 4 MiB，所有请求沿用公网地址校验和重定向检查。不会执行第三方页面脚本。只有浏览器执行动态脚本、交互验证后才能产生地址的接口，或其他未适配的私有流程，不保证兼容；提取失败时会继续尝试下一条接口。

解析、元数据和资源站请求由服务器发起，服务器必须能连接这些服务。取得地址后，媒体源仍须能被观看者访问并满足跨域要求；依赖对方 Cookie、特定 Referer、IP 绑定或 DRM 的地址不一定能在本站播放。

### 剧集元数据与资源站

先开启播放器设置中的“显示剧集列表”，再按需要选择：

- **关闭“从资源站补全剧集”**：读取内置平台选集；自建元数据接口提供的 `episodes` 列表也可使用。
- **开启“从资源站补全剧集”**：先识别片名，再按顺序搜索配置的苹果 CMS 资源站；未找到匹配列表时回退到内置或自建列表。

完整列表位于顶层 `list` 对象，`data` 是影片信息。例如：

```json
{
  "data":{"name":"示例剧集","episode":"1","episodeAll":3},
  "list":{
    "1":{"cont":"第一集标题","url":"https://video.example/episode-1"},
    "2":{"cont":"第二集标题","url":"https://video.example/episode-2"},
    "特别节目":{"cont":"幕后故事","url":"https://video.example/special"}
  }
}
```

对象键是节目标签，可能含非数字名称。程序按返回顺序保留有效条目，按当前原链接定位；列表计数是条目数，不能解释成全部为正片集数。列表 URL 是平台播放页，播放时仍需可用的解析接口。

选集面板优先显示作品海报；海报缺失或加载失败时，使用内置列表中与当前原视频 URL 精确匹配的 `cover`，按横向比例显示当前集封面。不会借用第一集或其他作品的图片；两类图片均不可用时才显示“暂无封面”。自建元数据可在 `data.pic` 中提供作品海报。浏览器选集缓存有效期为 10 分钟，并绑定当前原视频链接，切集时重新读取对应元数据。

“剧集元数据接口”用于资源站搜索前识别片名和集号，留空时复用内置完整响应中的影片信息。需要使用单独的元数据请求时填写：

`type=1` 与完整列表请求用途不同，不要求它返回 `list`。这类接口仅返回元数据时，程序会在未取得选集的情况下补请求完整内置列表。上游提供的数量可能较旧，不会截断实际列表。内置服务的可用性与平台覆盖由上游决定；也可以在此字段填写自己的接口前缀或 `{url}` 模板，支持以下扁平响应，或将相同字段放在 `data` 对象中：

```json
{"name":"示例剧集","episode":1,"episodeAll":12}
```

字段用途：`name` 是搜索片名，`episode` 是当前集号，`episodeAll` 是上游提供的总集数提示。总集数提示不会截断资源站实际返回的列表。B站季度页可按明确的分集 ID 定位；内置选集使用官方正片列表，过滤预告和彩蛋。列表无法确认当前视频时会显示说明，不按集号猜测匹配。

“资源站 / 苹果 CMS 搜索接口”每行一个，例如：

```text
https://cms.example.com/api.php/provide/vod/?ac=videolist&wd=
```

接口应返回包含 `vod_name`、`vod_play_from`、`vod_play_url` 的 MacCMS 列表数据。标准 `/api.php/provide/vod/` 基础地址也可直接填写，程序会补齐搜索参数；网站首页无法代替接口。已有查询参数和 `{url}` 模板会原样保留。

通过资源站补全网页选集时，只显示**包含当前视频原链接**的候选结果；存在多个候选时选取条目最多的一部，不把同名但不相关的内容混在一起。多个资源站按配置顺序尝试，先采用能够匹配当前视频的结果。输入片名时按片名检索。

自建元数据接口还可返回 `episodes` 数组作为直接剧集列表：

```json
{
  "name":"示例剧集",
  "episode":1,
  "episodeAll":2,
  "episodes":[
    {"name":"第1集","url":"https://video.example.com/episode-1"},
    {"name":"第2集","url":"https://video.example.com/episode-2"}
  ]
}
```

接口不可用或没有匹配结果时，播放器显示说明，不生成虚假的剧集。本站 `api.php?type=vlist` 通过 POST 接收播放器生成的 `vodkey` 签名令牌；外部接入只需传递播放页的 `url` 参数，不需要自行拼接或复制令牌。


### 弹幕库

新安装默认使用本站 `danmaku.php`。弹幕按视频标识存入站点数据库，支持发送、列表、举报和发送间隔限制；举报记录由站长处理。空视频分组也可绑定，首次发送后保存，其他观看者可以读取同一集的弹幕。

可在“弹幕服务列表”中手动填写多个完整 HTTP(S) 地址，**每行一个，最多 10 个**：

```text
https://danmaku.example.com/dmku/
https://another.example.com/dmku/
https://player.example.com/danmaku.php
```

- 按顺序读取；请求失败、无有效视频弹幕或只有系统公告时，尝试下一个库。
- 采用第一个返回有效视频弹幕的库，不合并多个库的内容。
- **允许创建空库的接口**：从服务列表复制支持写入、能自动创建视频分组的地址，每行一个。没有库返回有效弹幕时，使用其中首个读取成功、弹幕为 0 的接口；其他库失败不会让这个空库丢失绑定。留空时不选用外部空库。
- **使用本站数据库兜底**：默认开启。外部库全部失败，或没有允许创建的可用空库时，读取并绑定本站 `danmaku.php`，有历史弹幕就显示，没有则等待首次发送。接口失败、格式错误或返回其他视频的标识，都不会被当作可用空库。
- 发送绑定当前实际采用的库，不会因失败自动改投另一库，也不会自动重复 POST。
- 库未提供兼容的举报接口时，不显示举报入口。
- 服务列表留空等同于使用本站库；关闭弹幕开关会隐藏播放器弹幕模块。

兼容库沿用播放器实际计算出的分组 ID，即 `baseId + ' P' + 分集标记`，读取的 `id` 与发送的 `player` 保持一致，不再截短或二次转换。迁移已有站点时，可在播放链接中传入与原站相同的 `id` 和 `sid`；例如 `id=XX&sid=1` 对应 `P1`，请对中文参数正确编码。未提供 `id` 时本站使用原视频链接的完整 MD5 作为默认标识，这不保证与其他站点的已有分组相同。按其协议使用原视频链接读取，并使用对应 MD5 发送。

弹幕列表读取当前选中库的播放弹幕，数量按有效记录统计；部分库的 `ac=get` 只返回公告，因此不以该结果替换播放列表。列表不显示用户或 IP 类内部标识；发送成功由服务端响应确认。

每条地址必须以 `https://` 或 `http://` 开头；`https//`、`//域名/路径`、裸域名和相对路径会被拒绝，不做自动补全。仅使用本站内置库时留空；如需把本站库加入多个来源，可填写本站 `danmaku.php` 的完整地址。HTTPS 播放页应使用 HTTPS 弹幕服务，避免浏览器阻止混合内容。

### 本地弹幕管理

登录后台后打开“本地弹幕”，可查看弹幕总数、视频分组及待处理举报，按内容或昵称搜索、按完整视频编号筛选，或只查看被举报弹幕。列表每页 25 条，点击视频编号可查看同一分组；当前数据库保存的是视频编号，不能直接把它当作片名检索。

切换到“视频分组”可按编号搜索分组，查看每组的弹幕数、举报数和最近提交时间，并跳转到该组弹幕。支持单组或选择本页分组后批量清空，确认窗口会列出分组与影响数量。分组由已有弹幕自动汇总，清空会删除所选组当时已有的弹幕及关联举报；之后收到新弹幕时，分组会再次出现。

支持单条删除、选择本页弹幕后批量删除，以及查看和忽略举报。删除弹幕会同时清除关联举报；忽略举报只清除所选弹幕的举报记录，保留正文。执行前会显示数量与内容摘要并要求确认，删除的记录无法撤销。已打开播放器中的旧弹幕在下次重新读取后更新。

在同一页面展开“屏蔽词设置”，每行填写一个词后保存，最多 200 个，每个最多 100 字。服务端按包含关系检查新弹幕正文和昵称，忽略英文大小写、空白、零宽字符及全角英文数字；命中后拒绝入库，直接调用发送接口也会检查。留空并保存可关闭过滤。规则不会下发到公开播放器，也不会自动删除旧弹幕；已存在的广告可检索后批量处理。请优先使用明确的广告词，过短的词可能拦截正常交流。

此页面仅管理本站数据库，不会修改外部弹幕服务。所有管理请求均需管理员登录和 CSRF 校验；页面不展示访客 IP 或内部身份哈希。已有站点保留原数据库升级即可，无需重新安装。

## 画中画与浏览器行为

默认画中画移动原播放器到 Document Picture-in-Picture 窗口，保留同一个视频元素、进度和弹幕。小窗不显示发送区、悬停说明、重复的退出或全屏按钮；左侧为播放、时间、弹幕开关，右侧为倍速菜单与竖向音量。弹幕开关使用清晰的开、关两态图标，勾选色及倍速选中色跟随播放器主题；控件间距随窗口宽度调整。

关闭系统小窗，或点击主页面的返回按钮，可恢复原播放器及完整控件。页内浮窗还可以按 Esc 返回；打开菜单时，Esc 先关闭当前菜单。

Document PiP 需要浏览器支持、用户点击和安全上下文，通常使用 HTTPS 或 localhost。嵌入 iframe 或受浏览器策略限制时，可能改用页内浮窗；页内浮窗不会置顶到其他应用之上。开启“原生画中画”后使用浏览器的视频小窗，原生窗口不包含网页弹幕层。

自动开播、后台播放、编码解码、真实帧预览和 Web Audio 音效均受浏览器与媒体源约束。音效加载方式被片源拒绝时会恢复原声；不会通过关闭 HTTPS 校验来绕过问题。

## Web 服务器部署

### Apache

启用 PHP、`mod_rewrite`，并允许站点目录读取随包提供的 `.htaccess`（通常为 `AllowOverride All`）。保留根目录和私有目录中的访问限制文件，关闭目录浏览。

### Nginx 

Nginx 不读取 `.htaccess`。在该站点的 `server` 中、通用 PHP `location` 之前放入以下拒绝规则：

```nginx
location ~* ^/(?:src|tools|class|includes|var|Cache|tests)(?:/|$) {
    deny all;
}
location = /config.php { deny all; }
location = /install.lock { deny all; }
location ~* \.(?:bak|zip|sql|log)$ { deny all; }
location ~ /\.(?!well-known(?:/|$)) { deny all; }
```

上例按独立域名根目录部署。若放在子目录中，应为规则加上相应目录前缀。只补充这些规则；确认站点选择的 PHP 版本与扩展正确，并测试、重载 Nginx 配置。

站点的常规 PHP 处理段还应检查目标文件存在，例如 `try_files $uri =404;`，并使用实际 PHP-FPM / FastCGI 地址。

### IIS

配置 PHP FastCGI，使用根目录的 `web.config`，启用 Request Filtering 并关闭目录浏览。保留 `hiddenSegments` 对私有目录的限制以及配置、安装锁的访问限制。

### HTTPS 证书与外部请求

PHP cURL 始终验证服务器证书。已设置 `curl.cainfo` 时使用管理员的 CA 配置；未设置时使用 `assets/vendor/certificates/cacert.pem`。请保留证书包及其许可证，并随依赖更新维护。遇到 HTTPS 请求失败时检查 CA、系统时间、DNS 和网络，不要关闭证书验证。

在项目根目录构建：

```sh
node tools/build-player.cjs
```

构建工具只使用 Node.js 内置模块，不需要安装打包器。修改 `src/player/` 后重新构建，并同步相应 `assets/player/` 产物；PHP、后台和独立说明页的修改直接随文件部署。
